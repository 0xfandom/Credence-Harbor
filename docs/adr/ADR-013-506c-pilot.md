# ADR-013 — Select US Rule 506(c) pilot (selected design; legal signoff G0 required)

**Date:** 2026-11-23
**Decision:** One US issuer/one security class/one accredited-investor Rule 506(c) offering with US-only pilot investor eligibility. Public marketing only after signed issuer/legal approval; reasonable steps to verify every purchaser before irrevocable purchase; Rule 506(d) covered-person checks, investor/issuer record, Form D and state notices. Partner-managed USD funds; platform is software layer not unregistered placement agent; broker-dealer necessity determined by transaction and fee model.

**Alternatives rejected for R1:** Reg A, Reg CF, Reg S, global investing, issuer-issued internal currency, tokenization-dependent sale.

**Consequence:** No default $100 minimum, secondary trading or guaranteed appreciation; G0-G4 mandatory and independently signed.
