# ADR-015 — Onchain security issuance is not an R1 blocker

**Status:** Selected design, deployment gated G5.
**Decision:** The legally effective securityholder register is issuer/appointed agent owned, R1 has no production blockchain mint. SC work may run testnet/fork and formal assurance in parallel. Future ERC-3643 representation requires holder-ack evidence, signed EIP-712 permits, role-separated operators, audit and registrar position reconciliation. No independent onchain resale or DeFi composability.
